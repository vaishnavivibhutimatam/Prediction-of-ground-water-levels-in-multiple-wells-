# Prediction of Groundwater Levels in Multiple Wells Using Machine Learning

This project predicts **groundwater levels in multiple wells** using **Machine Learning algorithms**.  
It analyzes historical well water data, learns patterns, and forecasts future groundwater levels to support better water resource management.

---

## 📌 Project Overview

Groundwater is a critical resource used for drinking, agriculture, and industrial purposes.  
Accurately forecasting groundwater levels helps in:

- Preventing water scarcity  
- Planning irrigation effectively  
- Managing drought conditions  
- Maintaining sustainable groundwater usage  

This project uses machine learning to predict groundwater levels based on well data from CSV files.

---

## 🧠 Machine Learning Model

The project uses supervised learning algorithms such as:

- **Linear Regression**
- **Random Forest Regressor**

(Your `main.py` decides which algorithm is used.)

The model:

1. Loads input data from CSV files  
2. Preprocesses the dataset  
3. Splits data into training & testing  
4. Trains the machine learning model  
5. Predicts groundwater levels  
6. Generates results in HTML format
